# 정원 GitHub 자동 저장과 복원

Android 앱 하단의 정원 저장 → GitHub 연결에서 비공개 저장소와 fine-grained token을 연결합니다. 기본 저장소는 `SimpleorNothing/files`입니다. 토큰에는 선택한 저장소에 대한 Contents: Read and write 권한만 부여하세요. 토큰을 채팅이나 소스 코드에 넣지 마세요.

정원 목록, 개인 배경 사진, 성장 시간, 포인트, 수확 기록, 집중 시간과 배치 설정을 `mind-garden/app-state.json`에 저장합니다. 토큰은 Android Keystore로 암호화하여 기기에 보관하며 WebView에 제공하지 않습니다. 공개 저장소 저장은 거절합니다.

연결 후 기기 변경을 2초마다 감지하여 자동 저장합니다. 저장 실패는 기기 데이터와 미전송 상태를 유지하고 10초 후 재시도합니다. 동시에 다른 기기에서 수정한 경우 GitHub의 최신 파일을 덮어쓰지 않고 복원 선택을 기다립니다.

새 설치 후 같은 저장소와 토큰을 연결하면 앱 초기화 전에 GitHub 기록을 자동 복원합니다. 재설치는 인증 정보도 삭제하므로 연결을 한 번 다시 해야 합니다. 로그인 없이 완전 자동 복원을 제공하지 않습니다. 기기에 이미 기록이 있고 GitHub 내용이 다른 첫 연결은 자동 덮어쓰기하지 않으며, GitHub에서 복원 선택 시 기기 사본을 남긴 뒤 복원합니다.

기존 APK의 로컬 데이터는 이 기능을 적용하고 연결하기 전까지 GitHub에 올라가지 않습니다. 기존 앱 삭제 또는 서로 다른 앱 ID 설치는 데이터를 이전하지 않습니다. 서명이 다른 APK로 기존 설치를 업데이트할 수 없습니다.

웹 버전은 기존 로컬 저장을 유지합니다. GitHub 동기화는 인증 토큰을 안전하게 보관하는 네이티브 Android 앱에서 제공됩니다. 사진을 포함한 저장 파일 상한은 12MB이며 기기 localStorage 용량도 적용됩니다.
